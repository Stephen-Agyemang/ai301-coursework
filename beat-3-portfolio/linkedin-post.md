For the past few months, I have been working on the open-source project Home Assistant for my AI 301 course with CodePath, where I opened a pull request on GitHub. My contribution was supposed to update how Home Assistant works with the BT Home Hub 5 router, so people could set it up from the app instead of editing a config file, a change the project is making across many integrations.

What is Home Assistant, you might ask? It is free, open-source software that people run locally to make their homes smarter and more automated, for everyday things like turning on the lights or TV, and for keeping their home secure.

I implemented a setup screen in the app, automatic moving of users' old settings, alerts when something needs fixing, and 29 automated tests that run every line of the new code.

Though all checks passed, the pull request was closed when a maintainer explained that the project only accepts these changes from contributors who can test them on the actual router, which I don't own.

One thing that stuck with me is that the result of a contribution is not all that matters, but also what you learn along the way. For me, that was learning how to start contributing in the first place and the steps every project expects, especially reading all of its documentation before building anything.

I am excited to continue contributing to open-source projects.
